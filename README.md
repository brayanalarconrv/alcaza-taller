# Taller de mockups · Grupo Alcaza

Robot que cada 15 minutos revisa la fila del taller del Estudio (grupoalcaza.com/estudio). Si hay colecciones esperando mockups, abre la Estación de taller en un Chrome en la nube, hace las fotos y se apaga. Si no hay nada, termina en segundos.

- Clave: secreto `TALLER_CLAVE` (Settings → Secrets and variables → Actions). Es la misma clave del Estudio.
- Correrlo a mano: pestaña Actions → "Taller de mockups" → Run workflow.
